# AIE 上海大会研究分享｜使用说明

## 打开演讲

1. 完整解压 `AIE-Shanghai-2026-complete.zip`，不要只解压 HTML。
2. 保持 `AIE上海大会研究分享.html` 与 `assets` 文件夹的相对位置不变。
3. 使用 Chrome 或 Edge 打开 `AIE上海大会研究分享.html`。
4. 片头可开启声音播放，也可点击“跳过片头”。方向键翻页，`Home` 到封面，`End` 到参考资料，`F` 进入全屏。
